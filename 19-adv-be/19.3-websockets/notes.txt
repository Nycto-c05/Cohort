scaling web servers: Assume some site has their own server, which has fleet of ws servers
-sticky connection: all users in a room are connected to the same server aka sharding ig (irresp what region u from, u go to same ws server)

-another way, one region user connect to their region server closer to em, but then each ws server must also comm with each other (movement of india user must reflect to usa user) hence support for more users

So if ppl from diff regions in same room but diff ws servers, then we can implement a pub/sub where u publish ur action/movement and everyone who is subbed to the same room will get to see the action

-Horizontal scaling usually in Websocket
